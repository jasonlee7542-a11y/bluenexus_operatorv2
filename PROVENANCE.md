# Consolidation record

This application consolidates the two projects supplied for review:

- `bluenexus-analytics-pipeline-yuwei/bluenexus-analytics-pipeline-main`: core
  ingestion, process features, historical models, process rules, brand assets
  and the principle of explicit evidence/coverage presentation.
- `BlueNexus_Operator_Final`: prior-calendar IQR screening, broader equipment
  investigation concepts, remote/site playbooks and attendance/handoff workflow.

The new service, shared case schema, operator work-log validation, interface,
chart helpers, delivery package and integration tests are a consolidation/refinement.
Original project directories were not changed as part of this build.

Key differences: one ingestion path; no electrical rescaling; conditional Celsius
labels; priority-first home; one case grouping policy; production-adjusted and peer
energy views together; exploratory scores moved to methods; portable saved reviews;
no duplicate app entry points. No project claims are treated as verified operational
outcomes. Optional fleet/edge demonstrations are not part of the dashboard narrative.

BlueNexus logo is carried over from the supplied Yuwei project. Montserrat is bundled
with its SIL Open Font License in `static/fonts/OFL.txt`. No new license is asserted
over the supplied projects, trademarks or restricted dataset.
